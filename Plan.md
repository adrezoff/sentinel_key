Тема проекта:
Разработка системы автоматического обнаружения секретов в Git-репозиториях с использованием методов статического анализа и LLM.
План проекта:
1.	Анализ существующих подходов к обнаружению секретов в Git-репозиториях и формирование требований к системе.
2.	Разработка архитектуры системы и базовых моделей данных.
3.	Реализация получения истории Git, анализа коммитов и diff, включая инкрементальную обработку.
4.	Реализация извлечения потенциальных секретов из добавленных строк.
5.	Разработка локальных детекторов: регулярные выражения, анализ энтропии и контекстный анализ.
6.	Реализация системы оценки риска и отбора подозрительных кандидатов.
7.	Реализация асинхронного pipeline и параллельной обработки данных.
8.	Интеграция LLM для дополнительной классификации подозрительных кандидатов.
9.	Реализация хранения состояния, результатов анализа и обработки ошибок.
10.	Создание CLI-интерфейса, интеграционное тестирование и демонстрация работы системы.
11.	Подготовка документации и презентации проекта.
Роли в команде:
Андрей — разработка локального анализа: работа с Git-историей и diff коммитов, извлечение кандидат, реализация регулировок, модель энтропии и context-анализаторов, оценка рисков и принятие решений, тестирование.
Ваня — разработка pipeline и LLM-компонента: асинхронная архитектура и параллельная обработка, интеграция LLM, prompt и классификация предполагаемых секретов, маскирование и сантитаризация секретов , retry-policy и обработка ошибок, хранение результатов и интеграционное тестирование.
Оба участника совместно занимаются проектированием архитектуры, интеграцией компонентов, документацией и подготовкой демонстрации.
Инструментарий и технологии:
•	Язык: Python
•	Git: Git, Git CLI / библиотеки для работы с Git.
•	Асинхронность: asyncio, asyncio.Queue, ThreadPoolExecutor.
•	Анализ секретов: регулярные выражения, энтропия Шеннона, контекстный анализ, система оценки риска.
•	ИИ: LLM API для классификации подозрительных кандидатов.
•	Хранение: PostgreSQL.
•	Интерфейс: CLI.
•	Тестирование: pytest и интеграционные тесты.
