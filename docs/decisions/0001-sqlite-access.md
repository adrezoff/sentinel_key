# ADR 0001: доступ к SQLite через стандартную библиотеку

- Статус: принято
- Дата: 2026-10-22

## Контекст

Проекту нужен асинхронно доступный слой хранения, но менеджер зависимостей и
сторонний SQLite-драйвер ещё не выбраны. SQL должен оставаться только в модуле
`storage`, а операции фиксации результата должны быть атомарными.

## Решение

Использовать `sqlite3` из Python 3.11. Один `SqliteStorage` владеет одним
соединением с `check_same_thread=False`. Вызовы драйвера выполняются через
`asyncio.to_thread` и защищаются `asyncio.Lock`. Записывающие операции используют
`BEGIN IMMEDIATE`; файловые базы работают в WAL-режиме. Составная атомарная
операция оформляется callback-функцией для `run_in_transaction`, получающей
`StorageSession` с методами записи доменных моделей.

## Последствия

- Нет новой зависимости и отдельного event loop внутри драйвера.
- Один экземпляр хранилища сериализует операции; этого достаточно для SQLite и
  раннего прототипа, а несколько процессов координируются блокировками SQLite.
- Callback транзакции синхронный и не должен выполнять сеть, Git или другую
  бизнес-логику.
- При росте нагрузки реализацию интерфейса `Storage` можно заменить, не меняя
  доменные модели и вызывающие модули.
